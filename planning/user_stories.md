# User Stories

Reference the Writing User Stories final project guide in the course portal for more information about how to complete each of the sections below.

## Outline User Roles

Student: a user who is managing their coursework and using Cadence to plan and track their daily study tasks

## Draft User Stories

1. As a Student, I want to create an account, so that my tasks and plans are saved and I can come back to them across sessions.
2. As a Student, I want to set a weekly goal listing what I want to accomplish that week, so that my daily plans work toward something bigger than just today's to-do list.
3. As a Student, I want to add a task with an estimated time, priority, and difficulty, so that the planner has enough information to schedule it sensibly.
4. As a Student, I want to organize my tasks by course, so that I can see my workload for each class separately instead of one long undifferentiated list.
5. As a Student, I want to check in each morning with my energy and focus level, so that today's plan reflects how I'm actually doing, not just my raw task list.
6. As a Student, I want Cadence to generate a daily plan based on my check-in and weekly goal, so that I don't have to decide what to work on when I'm already tired or unfocused.
7. As a Student, I want harder tasks prioritized on days I report high energy and lighter tasks on low-energy days, so that my plan matches what I can realistically get through that day.
8. As a Student, I want to mark a task as completed or skipped for the day, so that skipped tasks stay part of my active weekly plan and can be picked again on another day, instead of disappearing or being lost.
9. As a Student, I want unfinished tasks from the week to roll into next week's plan automatically, so that a rough week doesn't feel like a failure or cause me to lose track of something.
10. As a Student, I want to reschedule a task to a different day, so that I can adjust my plan without losing track of something I still need to do.
11. As a Student, I want to see how much of my weekly goal I actually completed, so that I can notice patterns in my own productivity over time.
12. As a Student, I want to filter and sort my tasks by course, priority, or due date, so that I can quickly find what needs my attention first.
13. As a Student, I want to be warned if I try to add a task with a due date that's already passed, so that I don't accidentally set myself an impossible deadline.
